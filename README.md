# 🖥️ STEM System Monitor

Сучасний застосунок для моніторингу системних ресурсів операційної системи в реальному часі. Проєкт розроблено в рамках STEM-проєкту з дисципліни "Операційні системи".

Програма є альтернативою стандартному Диспетчеру завдань Windows. Вона зчитує показники датчиків комп'ютера, будує динамічні графіки та інтегрується з нативною системою сповіщень ОС для попередження користувача про перевантаження ресурсів.


## ✨ Основні можливості

*   **Моніторинг Процесора (CPU):** Загальне завантаження у відсотках.
*   **Моніторинг Пам'яті (RAM):** Використана оперативна пам'ять у Гігабайтах (ГБ) з автоматичним розрахунком загального обсягу системи.
*   **Моніторинг Дисків (I/O):** Відстеження швидкості читання/запису (МБ/с). За допомогою інтеграції з WMI (PowerShell) програма отримує **реальні апаратні назви** встановлених SSD/HDD накопичувачів.
*   **Моніторинг Мережі:** Відстеження інтернет-трафіку (Мбіт/с).
*   **Динамічні графіки (Matplotlib):** Графіки автоматично масштабуються (змінюють ліміти осі Y) при пікових навантаженнях, а час відображається у зворотному напрямку (справа наліво, від 0 до 60 секунд) за стандартами професійних моніторів.
*   **Система сповіщень (Plyer):** Якщо навантаження на систему перевищує встановлені пороги (наприклад, процесор > 85%), програма відправляє нативне Push-сповіщення на робочий стіл. Реалізовано таймер затримки (cooldown), щоб уникнути спаму сповіщеннями.
*   **Сучасний UI/UX (CustomTkinter):** Інтерфейс підтримує миттєве перемикання між темною та світлою темами.

## 🛠 Технологічний стек

*   **Python 3.8+**
*   [psutil](https://github.com/giampaolo/psutil) — збір системних метрик (кросплатформно).
*   [customtkinter](https://github.com/TomSchimansky/CustomTkinter) — побудова сучасного графічного інтерфейсу (GUI).
*   [matplotlib](https://matplotlib.org/) — рендеринг графіків навантаження.
*   [plyer](https://github.com/kivy/plyer) — кросплатформний API для надсилання системних сповіщень.

## 🚀 Інструкція із запуску (Локально)

Слідуйте цим крокам, щоб запустити проєкт на вашому комп'ютері.

### 1. Клонування репозиторію
Відкрийте термінал (Command Prompt, PowerShell або термінал у вашому IDE) і виконайте команду:
```bash
git clone https://github.com/ВАШ_ЮЗЕРНЕЙМ/ВАШ_РЕПОЗИТОРІЙ.git
cd ВАШ_РЕПОЗИТОРІЙ
```

### 2. Створення віртуального середовища (Рекомендовано)
Щоб не засмічувати глобальний Python, створіть ізольоване середовище:
```bash
python -m venv .venv
```
Активація віртуального середовища (Windows):
```bash
.venv\Scripts\activate
```
*(Для macOS/Linux використовуйте: `source .venv/bin/activate`)*

### 3. Встановлення залежностей
Встановіть усі необхідні бібліотеки з файлу `requirements.txt`:
```bash
pip install -r requirements.txt
```

### 4. Запуск програми
Виконайте головний файл:
```bash
python system_monitor.py
```

## ⚙️ Налаштування порогових значень

Ви можете легко змінити пороги, при яких програма видаватиме сповіщення. Для цього відкрийте файл `system_monitor.py` і знайдіть словник `self.thresholds` (всередині класу `SystemMonitorApp`):

```python
self.thresholds = {
    "CPU": 85.0,                  
    "RAM": total_ram * 0.90,      
    "Disk": 100.0,                
    "Network": float('inf')       
}
```
Змініть ці значення на будь-які інші для тестування.
